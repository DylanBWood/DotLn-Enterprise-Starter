## Read before upgrading

No authority, schema or document root changes in the launchpad, and the `dotln-angular` registration is unchanged; `docs/control/budgets.json` returns `subagentCap` to 20 after the operator's authorized raise to 40 for this order's fan-out. In DotLn-Angular no dependency changes. `BasePaths` gains `Tools` and `ChildPaths` gains `Catalog`, so an exhaustive switch over either handles one more member. `DotlnMenu` is no longer exported from the root `@dotln-angular/ui` barrel: import it, the new `DotlnFilterMenu` and `MenuOption` from `@dotln-angular/ui/menu`, and `provideDotlnUi()` no longer installs the CDK `OverlayModule` globally because the menu imports it. The command-only utility project is renamed `workspace-tools` (its lint target is `workspace-tools:lint`), and the `tools` name belongs to the feature library. `npm run check:fixtures` now also runs `catalog:check`, and `npm run check:bundle` runs in CI. The operator action after both merges is to fast-forward `main`, run the bootstrap, and dispatch `resume: release close` in `main`, which closes the target worktree with the no-release outcome for the launchpad and the target's own release under its declared policy.
