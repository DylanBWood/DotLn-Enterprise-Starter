## Read before upgrading

No authority, schema or document root changes in the launchpad, and the `dotln-angular` registration is unchanged. In DotLn-Angular no dependency changes. The catalog schema is `tool-v1`: a row requires `definition`, `place` (with `chapter`), `related`, `hooks` and `verified`, and the `Tool` type gains them through `ToolContent`; the loader still reads `tool-v0` chunks for this one release, with an explicit unavailable-definition message, and the order that next touches the loader removes that reader. `catalog-summary.json` is `catalog-summary-v1`: `firstThree` is replaced by `sceneTools` and `chapters` per work. The catalog library exports `catalogShelf`, `contentsFor`, `searchReadings`, `restoreReading`, `chapterKey`, `workTitle`, `sceneTools` and `emptyReading` and no longer exports `firstThree`; `@dotln-angular/models` gains `HookDomain`, `isSceneTool`, `sceneTransformKinds`, `CatalogWork`, `CatalogChapter`, `CatalogSection`, `CatalogReadingState` and `ToolContent`. The catalog page events gain `workChosen`, `chapterChosen`, `sectionChosen`, `conceptOpened`, `relationFollowed`, `readingReturned` and `searched` and lose `toolSelected`. Persisted catalog state moves from `dotln-angular.catalog` to `dotln-angular.tools`; a stored value of the old shape is ignored. The `tool-list` and `tool-faces` composites, the `tool-v0` schema file, the `merge-checkpoints` script and the `with-definition.json` fixture are removed; `npm run catalog:join`, which takes the research run's directory as its argument, is added. `npm run lint:fixtures` leaves `workspace-tools:lint` and CI and becomes a helper for lint-policy changes; CI runs `nx run workspace-tools:lint` once and `nx affected` without it. Lint refuses `@dotln-angular/catalog` imports from presentational code. The operator action after both merges is to fast-forward `main`, run the bootstrap, and dispatch `resume: release close` in `main`, which closes the target worktree with the no-release outcome for the launchpad and the target's own release under its declared policy.
