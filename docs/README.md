# docs

The document roots of this launchpad, at the default layout (`dotln.config.json`
is absent). Each root's README states its convention; `UPSTREAM.md` at the
repository root names the kit's commit and the upstream documents the kit
points to.

- `docs/control/`
- `docs/evidence/`
- `docs/verifications/`
- `docs/final-reviews/`
- `docs/planning/`
- `docs/publication/`
- `docs/product/`
- `docs/discovery/`
- `docs/decisions/`
- `docs/releases/`
- `docs/observations/`
- `docs/work-orders/` — one scope authority per order, WO-NNN-<slug>.md, with **Model:** and **Effort:** as its leading metadata; its README is the index `npm run work-orders -- index` generates at the first lifecycle transition (activate)
- `docs/lineage/` — idea-ledger.md, an append-only idea history; its README is generated by `node scripts/lineage.mjs index` once a ledger exists
- `docs/intake/` — ignored, single-copy raw material
- `docs/workstreams/` — one document per outcome; the README holds the convention and template
- `docs/repositories/` — one profile per registered repository; the README holds the convention and template
